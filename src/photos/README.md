# 照片文件夹说明

```
src/photos/
├── home/          ← 首页全屏轮播用的照片
├── about/         ← About 页面展示的照片
├── series-01/     ← Works 里「学校」页面的照片
├── series-02/     ← Works 里「物质」页面的照片
└── series-03/     ← Works 里「探索时期」页面的照片
```

- 支持 jpg / jpeg / png / webp（照片会自动压缩为 webp）
- 暂不支持 tiff 格式：如有 tiff 照片，先转成 jpg/png（或让 Codex 帮你转换）
- 把照片放进对应文件夹，重新构建（`pnpm build`）或开发模式刷新即可自动显示
- **注意：新增照片文件后，需要重启开发服务器**（终端 Ctrl+C 后重新运行 `pnpm dev`），照片列表才会更新
- **左下角说明文字**：说明文件必须和照片放在**同一个文件夹**里——照片同目录放一个「同名 .txt」文件（如 `IMG_6384.jpg` ↔ `IMG_6384.txt`），只作用于该照片；或者在一个子文件夹里放一个 `说明.txt`（或 `caption.txt`），整组照片共用这段文字
- **排列顺序**：默认按文件名排序（建议用 `01_`、`02_` 前缀控制顺序）；设置了 `sortBy: "date"` 的系列（如「探索时期」）自动按拍摄时间排序
- **子文件夹**：系列照片可以按主题放进不同子文件夹（如 `series-03/老单反/`），页面会自动读取
- 每个系列文件夹里都有对应的 README.md 说明
